# RepoGuardian

Autonomous AI Agent System for Code Repository Management.

## Stack
- FastAPI + Python 3.12
- OpenAI GPT-4o
- PostgreSQL, Redis, ChromaDB
- React + TypeScript

## Quick Start
```bash
cd repoguardian
cp .env.example .env
docker compose up --build
```

- API: http://localhost:8000/redoc
- Dashboard: http://localhost:3000
